## 💱 Projeto em Destaque — CambioPablo

### [CambioPablo](https://github.com/opablosantanaa/CambioPablo)

Aplicativo **Android nativo desenvolvido em Java** para consulta e conversão de moedas utilizando cotações em tempo real.

O projeto integra a **AwesomeAPI através do Retrofit**, realiza cálculos monetários com `BigDecimal` e mantém localmente o histórico das últimas conversões.

**Principais recursos:**

- 💵 Conversão de **USD, EUR, GBP, JPY e BTC para BRL**
- 🌐 Cotações em tempo real via **AwesomeAPI**
- 🔌 Consumo de API REST com **Retrofit + Gson**
- 🧮 Cálculos monetários utilizando **BigDecimal**
- 💾 Histórico local das últimas **20 conversões**
- 📱 Aplicativo Android nativo com suporte a **Android 6.0+**
- 🎨 Interface própria com tema escuro e componentes visuais personalizados
- 🧪 Testes com **JUnit** e infraestrutura para testes instrumentados com **Espresso**
- 📦 **APK disponível no próprio repositório**

`Java` `Android` `Retrofit` `REST API` `Gson` `SharedPreferences` `JUnit` `Espresso`

➡️ **[Ver projeto e baixar o APK](https://github.com/opablosantanaa/CambioPablo)**
